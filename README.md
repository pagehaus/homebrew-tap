# Homebrew tap for Pagehaus

```
brew install pagehaus/tap/pagehaus
```

Installs [pagehaus](https://github.com/pagehaus/cli), the command-line tool to preview plain HTML sites with Server
Side Includes, check them for broken links, and deploy them to [Pagehaus](https://pagehaus.app). On macOS and Linux,
Apple silicon, Intel and Arm. `brew upgrade pagehaus` gets new versions.

The formula is written by `update-formula.sh` from each release's checksums; a daily workflow updates it when there's
a new release.
